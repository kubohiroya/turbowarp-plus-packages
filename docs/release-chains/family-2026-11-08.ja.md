## 例外とレビュー

例外の指定は [`family-2026-11-08.exceptions.json`](family-2026-11-08.exceptions.json) です。
install・検証・公開の手順は 60 repo すべてで既存の package.json と `release.yml` から解決できました。
手順の上書き（`repositories`）は、実行の途中で見つかった次の 11 件だけです。

- **camera-calibration の prepare：** `THIRD_PARTY_NOTICES.md` は、同梱する依存（camera-source、data-editor）の版を「exact npm version `0.22.0`」のように本文に書き、`check-repo` が package.json と照合します。
  依存を上げると本文も直す必要があるので、既定の準備（`docs` → `build` → `samples:build`）の前に、入力 SHA の package.json から変わった依存の版を `` `旧版` `` → `` `新版` `` に置き換えます。
  旧版の表記が本文にちょうど 1 か所ないときは、推測せずに止まります。
- **diagnostic-overlay の prepare：** `check-repo` が `CHANGELOG.md` に今の版の節（`## [0.9.0]`）を求めます。
  既定の準備の前に、最初の版の見出しと同じ形で新しい版の節を足し、package.json の差分から依存の更新を `### Changed` に書きます。
  依存の変更がないときは止まります。
- **plus-editor の prepare：** 計画は document-editor の Git 参照（`4039927`）を npm の 0.1.0-rc.8 に置き換えます。
  PR CI の site build は、`site/source.json` の固定とインストールした依存を照合するので、既定の準備（`build`）の前に `site/source.json` を npm の固定へ書き換えます。
  書く値は #40（rc.1 を npm へ切り替えた PR）と同じ形で、`documentEditorSource: npm`、package-lock の integrity、タグ `v<版>` が指す commit です。
  package.json が Git 参照のままなら何もしません。
- **bubble・sesame・realtime-motion-capture-app・photogrammetry-app・time-space-sync-app・webrtc-qrcode-pairing-app の prepare：** pnpm の install は、`minimumReleaseAgeExclude` に新しい版を書き足すとき、その行をシングルクォートで書き直します。
  この 6 repo は `prettier --check .` で `pnpm-workspace.yaml` も検査するので、bubble はこの差で止まりました。
  既定の準備の前に、repo の prettier で `pnpm-workspace.yaml` だけを整えます。整形済みなら何も変わりません。
- **bubble の prepare（追加）：** bubble は自分の版を `src/extension.ts` の `EXTENSION_VERSION` に、同梱を勧める依存の版を `repo-policy.json` の `companionVersions` に書き、README・ブロックマニュアル・Pages にも「Bubble 0.17.2」「Asset Cache 0.7.0」と CDN の URL を書いています。`check-dist`・`check-repo` はこれらを package.json と照合します。
  prettier の整形のあとで、入力 SHA の package.json から変わった自分の版と依存の版を、これらの表記へ反映します。`EXTENSION_VERSION` がちょうど 1 か所ないときは止まります。
